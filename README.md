# Le Grand Cinéma - Front-end

Site de réservation de places pour le cinéma Le Grand Cinéma, en React.

## Branches

- main : la version stable, en production.
- develop : la branche d'intégration.

Chaque travail part de develop dans une branche préfixée, puis revient dans develop par une pull request :

- feature/ pour une fonctionnalité, par exemple feature/reservation-billet
- fix/ pour un bug, par exemple fix/calcul-tarif-seance
- hotfix/ pour une correction urgente, qui part de main et revient dans main et develop
- chore/ pour la configuration, les tests ou la documentation

Noms en minuscules, sans accents, mots séparés par des tirets.
